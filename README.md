# Программирование микроконтроллеров

Материалы практических и лабораторных занятий по дисциплине **"Программирование микроконтроллеров"** в ТУСУРе, направление подготовки [09.03.02 Информационные системы и технологии](https://edu.tusur.ru/work_programs/72024).

Курс построен вокруг платы **Arduino UNO R3** (микроконтроллер ATmega328P) и учебных наборов компонентов. Занятия проходят на реальном оборудовании; симулятор [Wokwi](https://wokwi.com/) используется как запасной путь для пропущенных занятий и домашней работы.

## Правила курса

### Техника безопасности

Обязательна к соблюдению всеми. Полный текст - в [занятии 1](Practice/01-safety-electronics/note.md) и [справочнике по железу](Hardware/README.md), кратко:

1. Собирайте и меняйте схему **только при отключённом питании**.
2. **Никогда не соединяйте питание с землёй** - ни перемычкой, ни через вывод микроконтроллера.
3. Проверяйте **напряжение питания модуля** до подключения: RC522, ILI9341 и модуль SD-карт работают от 3,3 В.
4. **Резистор на каждом светодиоде.**
5. Двигатели и сервоприводы питаются **от внешнего источника** с общей землёй.
6. **Лазерный модуль KY-008 не направляется в глаза** - ни свои, ни чужие, ни через отражение.
7. **Сеть 220 В не коммутируется** ни при каких условиях.

### Инструменты

- Занятия 1-5: Arduino IDE.
- Занятия 6-21 и все лабораторные: **PlatformIO** в VS Code.
- Проекты сдаются с флагами компиляции `-Wall -Wextra` **без предупреждений**.

### Требования к коду

Начиная с занятия 6:

1. Программа разделена на модули; в `main.cpp` только связывание.
2. `delay()` не используется в основном цикле.
3. `String` и динамическое выделение памяти не применяются.
4. Номера выводов и константы вынесены в `config.h`.
5. Начиная с занятия 11 драйверы устройств оформляются классами.

**Язык реализации.** Курс не навязывает единственный подход: задачи и лабораторные работы можно решать процедурно, полностью на C++ с классами или смешанно, с драйверами на регистрах. Допустимые пути и их границы описаны в [правилах лабораторных работ](Labs/README.md). Выбранный подход указывается в отчёте и обосновывается.

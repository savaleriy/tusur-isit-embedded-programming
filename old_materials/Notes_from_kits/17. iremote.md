## Инфракрасный приёмник

Создадим схему для приёма инфракрасных сигналов с помощью Arduino UNO и инфракрасного приёмника VS1838B.

### Необходимые компоненты

- Arduino UNO
- Инфракрасный приёмник VS1838B
- ИК-пульт
- Провода для соединения компонентов

### Инструкция по сборке схемы

1. Подключите вывод VCC приёмника VS1838B к выводу 3.3 V на Arduino UNO.
2. Подключите вывод GND приёмника к GND на Arduino UNO.
3. Подключите вывод OUT приёмника к цифровому выводу D11 на Arduino UNO.

### Схема подключения

![Схема подключения ИК-приёмника VS1838B к Arduino (D11, 3.3V, GND)](https://chip-edu.ru/lesson-content/arduino/16/png/ir_receiver.png)

### Код программы

```cpp
#include <IRremote.hpp>

#define IR_RECEIVE_PIN 11

void setup() {
    Serial.begin(9600);
    IrReceiver.begin(IR_RECEIVE_PIN);
}

void loop() {
    if (IrReceiver.decode()) {
        Serial.println(IrReceiver.decodedIRData.command, HEX);
        delay(200);
        IrReceiver.resume();
    }
}
```

### Принцип работы схемы

Приёмник VS1838B принимает ИК-сигналы от пульта и выдаёт на выход OUT декодированный цифровой сигнал. Arduino считывает его на пине D11. Библиотека IRremote обрабатывает протокол и извлекает код команды.

В `loop()` функция `IrReceiver.decode()` проверяет, был ли принят новый сигнал. Если да, код команды выводится в Serial в шестнадцатеричном формате. `IrReceiver.resume()` подготавливает приёмник к следующему сигналу. Это позволяет узнать коды кнопок вашего пульта для дальнейшего использования в проектах.

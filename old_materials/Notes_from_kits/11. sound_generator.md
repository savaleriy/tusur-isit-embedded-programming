## Генератор звуковой частоты

Создадим схему, которая позволяет воспроизводить мелодию с помощью пьезоизлучателя, управляемого микроконтроллером Arduino UNO.

### Необходимые компоненты

- Arduino UNO
- Пьезоизлучатель (пьезодинамик)

### Инструкция по сборке схемы

1. Подключите один контакт пьезоизлучателя к цифровому выводу D11 на Arduino UNO.
2. Подключите другой контакт пьезоизлучателя к земле (GND) на Arduino UNO.

### Схема подключения

![Схема подключения пьезоизлучателя к Arduino UNO (D11, GND)](https://chip-edu.ru/lesson-content/arduino/10/png/buzzer.png)

### Код программы

```cpp
int buzzer = 11;  // Пин 11 подключен к пьезоизлучателю

// Ноты для мелодии (частоты в Гц)
#define NOTE_B3  247
#define NOTE_C4  262
#define NOTE_D4  294
#define NOTE_E4  330
#define NOTE_F4  349
#define NOTE_G4  392
#define NOTE_A4  440
#define NOTE_B4  494
#define NOTE_C5  523

// Мелодия Jingle Bells (ноты и длительности)
int melody[] = {
    NOTE_E4, NOTE_E4, NOTE_E4,
    NOTE_E4, NOTE_E4, NOTE_E4,
    NOTE_E4, NOTE_G4, NOTE_C4, NOTE_D4,
    NOTE_F4, NOTE_F4, NOTE_F4, NOTE_F4,
    NOTE_F4, NOTE_E4, NOTE_E4, NOTE_E4, NOTE_E4,
    NOTE_E4, NOTE_D4, NOTE_D4, NOTE_E4,
    NOTE_D4, NOTE_G4
};

// Длительности нот: 4 = четвертная, 8 = восьмая и т.д.
int noteDurations[] = {
    8, 8, 4,
    8, 8, 4,
    8, 8, 8, 8,
    8, 8, 8, 8,
    8, 8, 8, 8, 4,
    8, 8, 8, 8,
    4, 4
};

void setup() {
    pinMode(buzzer, OUTPUT);
}

void loop() {
    for (int i = 0; i < sizeof(melody) / sizeof(melody[0]); i++) {
        int noteDuration = 1000 / noteDurations[i];  // длительность в миллисекундах
        tone(buzzer, melody[i], noteDuration);       // воспроизведение ноты
        delay(noteDuration * 1.30);                  // пауза между нотами
    }
    delay(2000);  // пауза перед повторением мелодии
}
```

### Принцип работы схемы

Схема использует функцию `tone()` Arduino для генерации звуковых колебаний заданной частоты на цифровом выходе D11. Пьезоизлучатель преобразует эти колебания в звук.

Вот как это работает:

- **Инициализация.** В функции `setup()` вывод D11 настраивается как выход.
- **Массив мелодии.** Мелодия «Jingle Bells» задаётся двумя массивами: `melody[]` содержит частоты нот в герцах (от NOTE_B3 до NOTE_C5), а `noteDurations[]` — длительности (4 — четверть, 8 — восьмая нота).
- **Воспроизведение.** В цикле `for` каждая нота проигрывается функцией `tone(buzzer, melody[i], noteDuration)`. Длительность в миллисекундах вычисляется как `1000 / noteDurations[i]` (например, 8 даёт 125 мс, 4 — 250 мс).
- **Паузы.** После каждой ноты выполняется `delay(noteDuration * 1.30)` — пауза чуть длиннее ноты для разделения звуков. После проигрывания всей мелодии — пауза 2 секунды, затем цикл `loop()` повторяется.

Таким образом, схема демонстрирует использование Arduino и функции `tone()` для воспроизведения мелодии на пьезоизлучателе.

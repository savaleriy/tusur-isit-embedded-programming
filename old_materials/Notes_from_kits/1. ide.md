## Подготовка среды разработки

Подготовка среды разработки — первый шаг на пути к освоению программирования и электроники с Arduino. Выбор подходящей IDE критически важен для комфортной работы. Arduino IDE 2.0 с интуитивным интерфейсом, улучшенной производительностью и встроенными инструментами отладки — удобный выбор и для новичков, и для опытных разработчиков. В этом уроке мы рассмотрим, как скачать, установить и настроить Arduino IDE 2.0 и подготовить всё необходимое для ваших проектов.

В инструкции описаны основные шаги установки и настройки Arduino IDE для Windows. Подробную документацию можно найти на [официальном сайте Arduino](https://docs.arduino.cc/software/ide-v2).

Рекомендуем скачивать Arduino IDE 2.0 из **Microsoft Store**.

![Установка Arduino IDE](https://chip-edu.ru/lesson-content/arduino/0/png/install1.png)

### Подключение платы и настройка IDE

Подключите плату Arduino к компьютеру и настройте Arduino IDE для работы с ней. В меню выберите **Tools** → **Board** → **Arduino AVR Boards** и в списке выберите **Arduino UNO**.

![Выбор платы Arduino UNO в меню Tools → Board](https://chip-edu.ru/lesson-content/arduino/0/png/install3.png)

Затем выберите порт, к которому подключена плата.

![Выбор порта подключения платы](https://chip-edu.ru/lesson-content/arduino/0/png/install4.png)

В правом нижнем углу окна отображаются выбранная плата и порт, которые будут использоваться при работе.

### Установка драйвера

При установке Arduino IDE обычно ставятся нужные драйверы, но плата Arduino Uno R3 из комплекта для связи с компьютером использует микросхему **CH340**. Для корректной работы может понадобиться отдельный драйвер. Драйвер для своей ОС можно скачать на [официальном сайте WCH](https://www.wch-ic.com/downloads/CH341SER_EXE.html).

### Проверка установки

После установки и настройки убедитесь, что всё работает и можно переходить к заданиям и проектам.

Для проверки используем пример **«Мигающий светодиод»**

![Пример «Мигающий светодиод» в Arduino IDE](https://chip-edu.ru/lesson-content/arduino/0/png/install5.png)

#### Принцип работы примера

Схема использует цифровой выход микроконтроллера для переключения светодиода между включённым и выключенным состояниями, создавая эффект мигания.

- **Инициализация.** Функция `setup()` вызывается один раз при запуске программы или при нажатии кнопки сброса. В ней вывод D12 настраивается как выход командой `pinMode(led, OUTPUT)` — микроконтроллер может устанавливать на нём уровень HIGH или LOW.
- **Включение.** Функция `loop()` выполняется циклически после `setup()`. Команда `digitalWrite(led, HIGH)` устанавливает D12 в HIGH — через светодиод протекает ток (анод через резистор к D12, катод к GND), светодиод светится.
- **Задержка.** `delay(1000)` — пауза 1 секунда, светодиод остаётся включённым.
- **Выключение.** `digitalWrite(led, LOW)` — ток через светодиод не идёт, он гаснет.
- **Повтор.** Снова `delay(1000)`, затем цикл повторяется.

Скомпилируем и загрузим этот проект на Arduino.

![Компиляция и загрузка программы на плату](https://chip-edu.ru/lesson-content/arduino/0/png/install5_upload.png)

Состояние компиляции и загрузки программы отображается в разделе **Output**.

### Установка дополнительных библиотек

Библиотеки позволяют легко подключать модули и датчики, не углубляясь в низкоуровневое программирование. Они содержат готовый код для управления оборудованием и сложных задач. Установка библиотек ускоряет и упрощает создание проектов.

В левом столбце редактора найдите иконки. Нажмите на значок **«Библиотека»** (Library Manager). Откроется список доступных библиотек; можно найти и установить нужную. В примере установим библиотеку **Ds1302** — нажмите **Install**.

![Менеджер библиотек, установка Ds1302](https://chip-edu.ru/lesson-content/arduino/0/png/install6.png)

Установка обычно занимает около минуты.

![Библиотека установлена, статус Installed](https://chip-edu.ru/lesson-content/arduino/0/png/install7.png)

Когда установка завершится, в менеджере библиотек у Ds1302 будет отображаться статус **Installed**.

Чтобы использовать библиотеку в скетче, подключите её в начале файла: `#include <Ds1302.h>`

![Подключение библиотеки в скетче](https://chip-edu.ru/lesson-content/arduino/0/png/image9.png)

## Управление сервоприводом с помощью потенциометра

Создадим схему, позволяющую управлять положением сервопривода с помощью потенциометра, используя плату Arduino UNO.

### Необходимые компоненты

- Arduino UNO
- Сервопривод Tower Pro SG90
- Потенциометр
- Провода для соединения компонентов

### Инструкция по сборке схемы

1. Подключите центральный вывод потенциометра к аналоговому входу A0 на Arduino UNO.
2. Подключите один из крайних выводов потенциометра к 5 V, другой — к GND на Arduino UNO.
3. Подключите сигнальный провод сервопривода к цифровому выводу D8 на Arduino UNO.
4. Подключите питание (+5 V) и землю (GND) сервопривода к соответствующим выводам на Arduino UNO.

### Схема подключения

![Схема: потенциометр на A0, сервопривод на D8](https://chip-edu.ru/lesson-content/arduino/15/png/servo_potentiometer.png)

### Код программы

```cpp
#include <Servo.h>

Servo servo1;
const int pinServo = 8;  // сервопривод на D8
const int POT = 0;       // потенциометр на A0
int valpot = 0;
int angleServo = 0;

void setup() {
    servo1.attach(pinServo);
}

void loop() {
    valpot = analogRead(POT);                              // чтение потенциометра (0–1023)
    angleServo = map(valpot, 0, 1023, 0, 180);            // масштабирование в угол 0–180°
    servo1.write(angleServo);                              // установка угла сервопривода
    delay(15);
}
```

### Принцип работы схемы

Потенциометр работает как делитель напряжения: центральный вывод даёт напряжение от 0 до 5 V в зависимости от положения ручки. Arduino считывает его аналоговым входом A0 и получает значение 0–1023.

Функция `map(valpot, 0, 1023, 0, 180)` переводит это значение в угол 0–180°. Команда `servo1.write(angleServo)` передаёт целевой угол сервоприводу. При повороте ручки потенциометра угол поворота сервопривода меняется плавно.

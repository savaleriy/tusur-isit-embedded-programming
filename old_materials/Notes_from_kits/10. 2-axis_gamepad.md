## Двухосевой джойстик

Создадим схему для чтения положения двухосевого джойстика и состояния его кнопки с помощью микроконтроллера Arduino UNO.

### Необходимые компоненты

- Arduino UNO
- Двухосевой джойстик KY-023
- Провода для соединения компонентов

### Инструкция по сборке схемы

1. Подключите GND джойстика KY-023 к GND на Arduino UNO.
2. Подключите +5 V джойстика KY-023 к 5 V на Arduino UNO.
3. Подключите вывод VRx джойстика к аналоговому входу A1 на Arduino UNO.
4. Подключите вывод VRy джойстика к аналоговому входу A0 на Arduino UNO.
5. Подключите вывод SW джойстика к цифровому входу D7 на Arduino UNO.

### Схема подключения

![Схема подключения джойстика KY-023 к Arduino (A0, A1, D7)](https://chip-edu.ru/lesson-content/arduino/9/png/joystick.png)

### Код программы

```cpp
const int axisX = A1;  // ось X (VRx) подключена к A1
const int axisY = A0;  // ось Y (VRy) подключена к A0
const int buttonPin = 7;  // кнопка джойстика подключена к D7
int valX, valY, valButton = 0;

void setup() {
    pinMode(buttonPin, INPUT_PULLUP);  // D7 как вход с подтягивающим резистором
    Serial.begin(9600);
}

void loop() {
    valX = analogRead(axisX);   // значение оси X
    valY = analogRead(axisY);   // значение оси Y
    valButton = 1 - digitalRead(buttonPin);  // кнопка (инвертированное значение)
    Serial.print("X:");
    Serial.print(valX, DEC);
    Serial.print(" | Y:");
    Serial.print(valY, DEC);
    Serial.print(" | Button: ");
    Serial.println(valButton, DEC);
    delay(500);
}
```

### Принцип работы схемы

Схема позволяет считывать аналоговые значения положения джойстика по осям X и Y, а также состояние кнопки. Аналоговые значения осей X и Y меняются в зависимости от положения ручки джойстика, а состояние кнопки изменяется при её нажатии.

Вот как это работает:

- **Инициализация.** В функции `setup()` настраивается цифровой вход для кнопки с подтягивающим резистором (`INPUT_PULLUP`) и инициализируется последовательное соединение.
- **Чтение значений.** В функции `loop()` происходит чтение аналоговых значений осей джойстика с помощью `analogRead(axisX)` и `analogRead(axisY)`. Состояние кнопки считывается через `digitalRead(buttonPin)` и инвертируется, так как кнопка при нажатии замыкается на землю.
- **Вывод данных.** Считанные значения выводятся в монитор порта для наблюдения.
- **Задержка.** Между итерациями цикла устанавливается задержка 500 мс для удобства чтения данных.

Таким образом, данная схема позволяет ознакомиться с аналоговым и цифровым вводом данных в Arduino, а также с основами работы с джойстиком и обработкой его сигналов.

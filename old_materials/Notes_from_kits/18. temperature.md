## Измерение температуры

Создадим схему для измерения температуры окружающей среды с помощью датчика LM35 и микроконтроллера Arduino UNO.

### Необходимые компоненты

- Arduino UNO
- Датчик температуры LM35
- Провода для соединения компонентов

### Инструкция по сборке схемы

1. Подключите вывод GND датчика LM35 к GND на Arduino UNO.
2. Подключите вывод Vout датчика LM35 к аналоговому входу A0 на Arduino UNO.
3. Подключите вывод Vin датчика LM35 к выводу 5 V на Arduino UNO.

### Схема подключения

![Схема подключения датчика LM35 к Arduino (A0, 5V, GND)](https://chip-edu.ru/lesson-content/arduino/17/png/temp_sensor.png)

### Код программы

```cpp
int raw = 0;
float temp = 0;

void setup() {
    Serial.begin(9600);
    pinMode(A0, INPUT);
}

void loop() {
    raw = analogRead(A0);
    temp = (raw * 5.0) / 1024.0 * 100.0;  // LM35: 10 мВ/°C
    Serial.println(temp);
    delay(1000);
}
```

### Принцип работы схемы

Датчик LM35 выдаёт напряжение, линейно зависящее от температуры: 10 мВ на 1 °C. При опорном напряжении 5 В и 10-битном АЦП Arduino один отсчёт соответствует 5/1024 ≈ 4,88 мВ.

Формула `(raw * 5.0) / 1024.0 * 100.0` переводит отсчёт АЦП в градусы Цельсия: сначала в напряжение (raw/1024 * 5 В), затем в температуру (напряжение в мВ / 10). Значение выводится в Serial каждую секунду.

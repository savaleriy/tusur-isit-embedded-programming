## Чтение аналогового сигнала с потенциометра

Создадим схему для демонстрации работы с аналоговыми входами Arduino UNO, используя потенциометр для ввода переменного напряжения.

### Необходимые компоненты

- Arduino UNO
- Потенциометр
- Провода для соединения компонентов

### Инструкция по сборке схемы

1. Подключите один из внешних контактов потенциометра к земле (GND) на Arduino UNO.
2. Подключите другой внешний контакт потенциометра к 5 V на Arduino UNO.
3. Подключите средний контакт потенциометра (вывод сигнала) к аналоговому входу A0 на Arduino UNO.

### Схема подключения

![Схема подключения потенциометра к Arduino UNO (GND, 5V, A0)](https://chip-edu.ru/lesson-content/arduino/8/png/reostat.png)

### Код программы

```cpp
void setup() {
    Serial.begin(9600);  // Инициализация последовательного порта со скоростью 9600
}

void loop() {
    int sensorValue = analogRead(A0);  // Чтение аналогового значения с потенциометра
    Serial.println(sensorValue);       // Вывод значения в монитор последовательного порта
    delay(1);                          // Задержка для стабилизации чтения
}
```

### Принцип работы схемы

Принцип работы данной схемы основан на преобразовании аналогового сигнала, который генерируется потенциометром, в цифровое значение с помощью аналогово-цифрового преобразователя (АЦП) в Arduino UNO.

Вот как это работает:

- **Инициализация.** При запуске Arduino выполняется функция `setup()`, где инициализируется последовательный порт для общения с компьютером.
- **Чтение аналогового сигнала.** В функции `loop()` с помощью функции `analogRead(A0)` происходит чтение аналогового значения с вывода A0, к которому подключен потенциометр.
- **Вывод данных.** Считанное значение `sensorValue` отправляется в монитор последовательного порта с помощью `Serial.println(sensorValue)`, где его можно увидеть.
- **Задержка.** Функция `delay(1)` обеспечивает небольшую задержку между чтениями для стабильности показаний.

Поворачивая ручку потенциометра, вы изменяете сопротивление, что приводит к изменению напряжения на среднем контакте. Arduino UNO считывает это напряжение и преобразует его в цифровое значение от 0 до 1023, которое отображается в мониторе последовательного порта. Это позволяет наблюдать за изменением аналогового сигнала в реальном времени.

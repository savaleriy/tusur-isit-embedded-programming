## Подключение ЖК-дисплея I2C

Создадим схему с ЖК-дисплеем на I2C-интерфейсе: на первой строке статичный текст «Hello», на второй — бегущая строка «Arduino!».

### Необходимые компоненты

- Arduino UNO
- ЖК-дисплей 16×2 с I2C (LCM1602 IIC)
- Провода для соединения

### Инструкция по сборке схемы

1. Подключите GND Arduino к GND дисплея.
2. Подключите 5 V Arduino к VCC дисплея.
3. Подключите A4 (SDA) Arduino к SDA дисплея.
4. Подключите A5 (SCL) Arduino к SCL дисплея.

### Код программы

```cpp
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);  // адрес 0x27 (или 0x3F у некоторых модулей)

void setup() {
    lcd.init();
    lcd.backlight();
}

void loop() {
    const char *text = "Arduino!";
    int len = strlen(text);
    int maxPos = 16 - len;

    for (int pos = 0; pos <= maxPos; pos++) {
        lcd.clear();
        lcd.setCursor((16 - 5) / 2, 0);
        lcd.print("Hello");
        lcd.setCursor(pos, 1);
        lcd.print(text);
        delay(300);
    }
    for (int pos = maxPos - 1; pos >= 0; pos--) {
        lcd.clear();
        lcd.setCursor((16 - 5) / 2, 0);
        lcd.print("Hello");
        lcd.setCursor(pos, 1);
        lcd.print(text);
        delay(300);
    }
}
```

### Принцип работы схемы

Дисплей подключается по I2C: два провода (SDA — A4, SCL — A5) вместо 6+ при 4-битном режиме. Адрес 0x27 распространён; если дисплей не работает, попробуйте 0x3F.

В `loop()` текст «Arduino!» (8 символов) прокручивается по второй строке: сначала вправо (pos от 0 до 8), затем влево. На каждом шаге экран очищается, снова выводится «Hello» по центру первой строки и «Arduino!» на позицию pos. Пауза 300 мс задаёт скорость прокрутки.

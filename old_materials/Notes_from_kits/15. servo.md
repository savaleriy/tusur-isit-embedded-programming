## Управление сервоприводом с помощью Arduino UNO

Создадим схему для демонстрации работы с ШИМ-выходами Arduino UNO, управляя углом поворота сервопривода.

### Необходимые компоненты

- Arduino UNO
- Сервопривод Tower Pro SG90

### Инструкция по сборке схемы

1. Подключите сигнальный провод сервопривода к цифровому выводу D9 на Arduino UNO.
2. Подключите питающий провод сервопривода к выводу 5 V на Arduino UNO.
3. Подключите заземляющий провод сервопривода к GND на Arduino UNO.

### Схема подключения

![Схема подключения сервопривода SG90 к Arduino (D9, 5V, GND)](https://chip-edu.ru/lesson-content/arduino/14/png/servo_privod.png)

### Код программы

```cpp
#include <Servo.h>

Servo myservo;
int pos = 0;

void setup() {
    myservo.attach(9);  // сервопривод на D9
}

void loop() {
    for (pos = 0; pos <= 180; pos += 1) {
        myservo.write(pos);
        delay(15);
    }
    for (pos = 180; pos >= 0; pos -= 1) {
        myservo.write(pos);
        delay(15);
    }
}
```

### Принцип работы схемы

Схема управляет сервоприводом Tower Pro SG90 с помощью библиотеки Servo. На выводе D9 генерируется ШИМ-сигнал, который задаёт угол поворота вала (0–180°).

В `setup()` сервопривод подключается к пину 9 через `myservo.attach(9)`. В `loop()` угол последовательно меняется от 0° до 180° и обратно; `myservo.write(pos)` передаёт целевую позицию сервоприводу. Пауза `delay(15)` даёт время на перемещение к новой позиции перед следующим шагом.

## Датчик освещённости на основе фоторезистора

Создадим схему для измерения уровня освещённости с помощью фоторезистора и микроконтроллера Arduino UNO.

### Необходимые компоненты

- Arduino UNO
- Фоторезистор (LDR)
- Резистор на 10 кОм
- Провода для соединения компонентов

### Инструкция по сборке схемы

1. Подключите один вывод фоторезистора к аналоговому входу A0 на Arduino UNO.
2. Подключите другой вывод фоторезистора к питанию 5 V на Arduino UNO.
3. Подключите один вывод резистора на 10 кОм к аналоговому входу A0, где уже подключён фоторезистор.
4. Подключите другой вывод резистора к земле (GND) на Arduino UNO.

### Код программы

```cpp
int light;  // переменная для хранения данных фоторезистора

void setup() {
    Serial.begin(9600);
}

void loop() {
    light = analogRead(0);   // чтение аналогового значения с A0
    Serial.println(light);   // вывод значения освещённости в монитор порта
    delay(100);              // задержка для стабилизации чтения
}
```

### Принцип работы схемы

Схема использует фоторезистор для измерения уровня освещённости. Фоторезистор изменяет своё сопротивление в зависимости от интенсивности падающего на него света. Вместе с резистором на 10 кОм он образует делитель напряжения, напряжение с которого подаётся на аналоговый вход A0 Arduino UNO.

Когда освещённость высокая, сопротивление фоторезистора уменьшается, и напряжение на A0 возрастает. Когда освещённость низкая, сопротивление фоторезистора увеличивается, и напряжение на A0 падает. Arduino UNO считывает это напряжение и преобразует его в цифровое значение от 0 до 1023.

В программе используется функция `analogRead(0)`, которая считывает аналоговое значение с пина A0. Значение выводится в монитор последовательного порта через `Serial.println(light)`, что позволяет наблюдать изменения освещённости в реальном времени.

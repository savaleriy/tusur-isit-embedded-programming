## Измерение температуры и влажности с помощью DHT11

Создадим схему для считывания температуры и влажности воздуха с помощью датчика DHT11 и Arduino UNO.

### Необходимые компоненты

- Arduino UNO
- Датчик температуры и влажности DHT11
- Провода для соединения компонентов

### Инструкция по сборке схемы

1. Подключите вывод Vcc датчика DHT11 к выводу 5 V на Arduino UNO.
2. Подключите вывод GND датчика DHT11 к GND на Arduino UNO.
3. Подключите сигнальный вывод S датчика DHT11 к цифровому выводу D2 на Arduino UNO.

### Код программы

```cpp
#include <DHT.h>

#define DHTPIN 2
#define DHTTYPE DHT11

DHT dht(DHTPIN, DHTTYPE);

void setup() {
    Serial.begin(9600);
    dht.begin();
}

void loop() {
    float humidity = dht.readHumidity();
    float temperature = dht.readTemperature();

    if (isnan(humidity) || isnan(temperature)) {
        Serial.println("Не удалось считать данные с датчика DHT11");
        return;
    }

    Serial.print("Влажность: ");
    Serial.print(humidity);
    Serial.print("%\t");
    Serial.print("Температура: ");
    Serial.print(temperature);
    Serial.println("°C");

    delay(2000);
}
```

### Принцип работы схемы

Датчик DHT11 измеряет влажность и температуру и передаёт данные по одному цифровому проводу (Single-bus). Библиотека DHT обрабатывает протокол и возвращает значения.

В `loop()` вызываются `dht.readHumidity()` и `dht.readTemperature()`. При ошибке чтения функции возвращают NaN — в этом случае выводится сообщение и выполняется `return`. Если данные корректны, влажность (в %) и температура (в °C) выводятся в Serial. Пауза 2 секунды ограничивает частоту опроса датчика.

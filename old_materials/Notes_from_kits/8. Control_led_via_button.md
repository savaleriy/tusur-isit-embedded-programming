## Управление светодиодом кнопкой

Создадим схему, позволяющую управлять включением светодиода с помощью кнопки, используя цифровые входы и выходы Arduino UNO.

### Необходимые компоненты

- Arduino UNO
- Красный светодиод
- Резистор на 220 Ом
- Резистор на 10 кОм
- Кнопка
- Провода для соединения компонентов

### Инструкция по сборке схемы

1. Подключите резистор на 220 Ом к аноду (длинная ножка) светодиода.
2. Подключите катод (короткая ножка) светодиода к земле (GND) Arduino UNO.
3. Подключите другой конец резистора на 220 Ом к цифровому выводу D10 на Arduino UNO.
4. Подключите один из выводов кнопки к цифровому входу D2 на Arduino UNO.
5. Подключите другой вывод кнопки к питанию 5 V на Arduino UNO.
6. Подключите резистор на 10 кОм между выводом D2 и землёй (GND) — подтягивающий резистор.

### Код программы

```cpp
const int LED = 10;     // Светодиод на D10
const int Button = 2;   // Кнопка на D2

void setup() {
    pinMode(LED, OUTPUT);    // D10 — выход
    pinMode(Button, INPUT);  // D2 — вход
}

void loop() {
    int buttonState = digitalRead(Button);
    if (buttonState) {
        digitalWrite(LED, HIGH);  // Кнопка нажата — светодиод включён
    } else {
        digitalWrite(LED, LOW);   // Кнопка отпущена — светодиод выключен
    }
}
```

### Принцип работы схемы

Схема позволяет управлять светодиодом кнопкой. Когда кнопка не нажата, подтягивающий резистор 10 кОм удерживает вход D2 в состоянии LOW — светодиод выключен. При нажатии кнопки вход D2 подключается к 5 V, `digitalRead` возвращает HIGH — светодиод загорается. Так демонстрируется совместная работа цифрового входа (кнопка) и выхода (светодиод) и простая обработка сигналов микроконтроллером.

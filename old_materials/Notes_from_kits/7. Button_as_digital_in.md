## Кнопка как цифровой вход

Рассмотрим, как подключить и использовать кнопку с микроконтроллером Arduino UNO для создания простого пользовательского интерфейса.

### Необходимые компоненты

- Arduino UNO
- Кнопка (Pushbutton)
- Резистор 10 кОм (подтягивающий)
- Провода для подключения

### Как устроена кнопка с 4 пинами

Часто используются тактовые кнопки с **четырьмя выводами**. Внутри они устроены так:

- Два пина с одной стороны корпуса соединены между собой; два пина с другой стороны тоже соединены между собой.
- Когда кнопка **не нажата**, эти две пары контактов не соединены — цепь разомкнута.
- Когда кнопку **нажимают**, подвижный контакт замыкает обе пары — все четыре вывода оказываются соединены.

Для подключения к Arduino достаточно использовать **любые два пина, расположенные по диагонали** (один с одной пары, один с другой). Тогда при нажатии между ними будет контакт, при отпускании — нет. Два других пина можно не использовать. Если подключить оба пина с одной стороны к одному проводу, а оба с другой стороны — к другому, кнопка будет работать так же.

### Инструкция по сборке схемы

1. Подключите один контакт кнопки к цифровому входу D2 на Arduino.
2. Подключите другой контакт кнопки к 5 V на Arduino.
3. Подключите один вывод резистора 10 кОм к земле (GND) на Arduino.
4. Подключите другой вывод резистора к тому же контакту кнопки, что и вход D2.

### Код программы

```cpp
// Цифровой вход D2 подключен к кнопке
int pushButton = 2;

void setup() {
    Serial.begin(9600);           // Скорость 9600 бод
    pinMode(pushButton, INPUT);   // Пин 2 как вход
}

void loop() {
    int buttonState = digitalRead(pushButton);  // Читаем состояние кнопки
    Serial.println(buttonState);               // Выводим в Serial Monitor
    delay(1);                                   // Задержка для стабильного считывания
}
```

### Принцип работы схемы

Схема использует кнопку как цифровой вход с подтягивающим резистором. Состояние кнопки выводится в монитор последовательного порта (Serial Monitor) в Arduino IDE.

- **Подтягивающий резистор.** Резистор 10 кОм подключён между GND и контактом кнопки (который соединён с D2). Когда кнопка не нажата, вход D2 подтянут к земле — на нём низкий уровень (LOW, 0).
- **При нажатии.** Кнопка замыкает цепь между 5 V и входом D2 — на D2 высокий уровень (HIGH, 1).
- **Чтение.** В `loop()` функция `digitalRead(pushButton)` возвращает LOW (0), когда кнопка отпущена, и HIGH (1), когда нажата.
- **Вывод.** `Serial.println(buttonState)` отправляет значение в компьютер; в Serial Monitor (9600 бод) можно наблюдать 0 или 1 в зависимости от состояния кнопки.

Таким образом, схема позволяет считывать нажатие кнопки и передавать это состояние в компьютер для отображения или дальнейшей обработки.

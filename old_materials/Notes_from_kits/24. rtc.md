## Часы реального времени с Arduino и RTC DS1302

Создадим часы реального времени (RTC) на Arduino UNO и модуле DS1302: время и дата сохраняются при отключении питания за счёт батарейки на модуле.

### Необходимые компоненты

- Arduino UNO
- Модуль RTC DS1302
- Провода для соединения

### Инструкция по сборке схемы

1. Подключите 5 V Arduino к Vcc модуля DS1302.
2. Подключите GND Arduino к GND модуля.
3. Подключите D10 к RST, D11 к DAT, D13 к CLK модуля DS1302.

### Код программы

```cpp
#include <Ds1302.h>

Ds1302 rtc(10, 13, 11);  // RST, CLK, DAT

const char* WeekDays[] = {
    "Пн", "Вт", "Ср", "Чт", "Пт", "Сб", "Вс"
};

void setup() {
    Serial.begin(9600);
    rtc.init();
    if (rtc.isHalted()) {
        Ds1302::DateTime dt = {
            .year = 24,
            .month = Ds1302::MONTH_FEB,
            .day = 25,
            .hour = 12,
            .minute = 0,
            .second = 0,
            .dow = Ds1302::DOW_TUE
        };
        rtc.setDateTime(&dt);
    }
}

void loop() {
    Ds1302::DateTime now;
    rtc.getDateTime(&now);

    static uint8_t last_second = 255;
    if (last_second != now.second) {
        last_second = now.second;
        Serial.print("20");
        Serial.print(now.year);
        Serial.print('-');
        if (now.month < 10) Serial.print('0');
        Serial.print(now.month);
        Serial.print('-');
        if (now.day < 10) Serial.print('0');
        Serial.print(now.day);
        Serial.print(' ');
        Serial.print(WeekDays[now.dow - 1]);
        Serial.print(' ');
        if (now.hour < 10) Serial.print('0');
        Serial.print(now.hour);
        Serial.print(':');
        if (now.minute < 10) Serial.print('0');
        Serial.print(now.minute);
        Serial.print(':');
        if (now.second < 10) Serial.print('0');
        Serial.println(now.second);
    }
    delay(500);
}
```

### Принцип работы схемы

DS1302 обменивается данными по трём проводам (RST, CLK, DAT). Библиотека Ds1302 управляет модулем. В `setup()` при первом запуске или после остановки RTC (`isHalted()`) задаётся дата и время. В `loop()` раз в полсекунды запрашивается текущее время; в Serial вывод только при смене секунды, чтобы не дублировать строки. Год задаётся двумя цифрами (00–99), в вывод добавляется префикс «20».

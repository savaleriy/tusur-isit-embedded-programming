## Индикатор на семисегментном дисплее

Создадим схему для демонстрации работы с цифровыми выходами Arduino UNO, управляя отображением на семисегментном индикаторе.

### Что такое семисегментный индикатор?

Это электронный компонент для отображения цифр (и некоторых букв), состоящий из семи светодиодных сегментов, расположенных в форме цифры «8». Часто добавляется восьмой сегмент — точка (DP) для десятичной запятой.

**Обозначение сегментов:** A — верхний горизонтальный, B — верхний правый вертикальный, C — нижний правый вертикальный, D — нижний горизонтальный, E — нижний левый вертикальный, F — верхний левый вертикальный, G — средний горизонтальный, DP — точка.

### Как работает индикатор

**С общим катодом (CC):** все катоды сегментов соединены вместе и подключаются к GND; чтобы включить сегмент, на его анод подаётся HIGH (+5 В).

**С общим анодом (CA):** все аноды соединены и подключаются к +5 В; сегмент включается подачей LOW (GND) на его катод.

В этой схеме используется индикатор с **общим катодом**. Каждый сегмент подключается к отдельному пину Arduino через резистор (220–1000 Ом), чтобы ограничить ток и не повредить светодиоды. Если горят все сегменты, ток может достигать 7× ~20 мА ≈ 140 мА — это стоит учитывать при питании от Arduino.

### Отображение цифр 0–9

Чтобы показать цифру, включают нужную комбинацию сегментов:

- **0:** A, B, C, D, E, F
- **1:** B, C
- **2:** A, B, D, E, G
- **3:** A, B, C, D, G
- **4:** B, C, F, G
- **5:** A, C, D, F, G
- **6:** A, C, D, E, F, G
- **7:** A, B, C
- **8:** все сегменты A–G
- **9:** A, B, C, D, F, G

### Необходимые компоненты

- Arduino UNO
- Семисегментный индикатор с общим катодом
- Резисторы на 1 кОм (8 штук)
- Провода для соединения компонентов

### Инструкция по сборке схемы

1. Подключите общий катод семисегментного индикатора к земле (GND) Arduino UNO.
2. Подключите каждый из сегментов (A–G) через резистор на 1 кОм к выводам D2–D8 соответственно.
3. Подключите резисторы к цифровым выводам Arduino UNO следующим образом:
    - ○ D2 к сегменту A
    - ○ D3 к сегменту B
    - ○ D4 к сегменту C
    - ○ D5 к сегменту D
    - ○ D6 к сегменту E
    - ○ D7 к сегменту F
    - ○ D8 к сегменту G

### Код программы

```cpp
// Выводы для сегментов A–G
const int led2 = 2;  // A
const int led3 = 3;  // B
const int led4 = 4;  // C
const int led5 = 5;  // D
const int led6 = 6;  // E
const int led7 = 7;  // F
const int led8 = 8;  // G

void setup() {
    pinMode(led2, OUTPUT);
    pinMode(led3, OUTPUT);
    pinMode(led4, OUTPUT);
    pinMode(led5, OUTPUT);
    pinMode(led6, OUTPUT);
    pinMode(led7, OUTPUT);
    pinMode(led8, OUTPUT);
}

void loop() {
    // Включаем сегменты по очереди (бегущий огонь)
    for (int i = 2; i <= 8; i++) {
        digitalWrite(i, HIGH);
        delay(200);
    }
    for (int i = 8; i >= 2; i--) {
        digitalWrite(i, LOW);
        delay(200);
    }
}
```

### Принцип работы схемы

Схема (см. рисунок выше) управляет отображением на семисегментном индикаторе: последовательно зажигаются и гаснут сегменты. Резисторы на 1 кОм ограничивают ток через каждый сегмент и защищают светодиоды от перегорания.

- **Инициализация.** В `setup()` выводы D2–D8 настраиваются как выходы.
- **Управление.** В `loop()` микроконтроллер по очереди устанавливает HIGH на выводах D2–D8 (сегменты загораются), затем по очереди LOW (гаснут), по 200 мс на каждый шаг.
- **Повтор.** Цикл повторяется — получается эффект «бегущего огня» по сегментам.

Схема демонстрирует управление несколькими выходами для индикации. Используя комбинации сегментов из таблицы выше, можно написать программу, которая поочерёдно отображает цифры от 0 до 9.

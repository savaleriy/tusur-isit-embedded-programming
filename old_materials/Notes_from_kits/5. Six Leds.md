## Шесть светодиодов

Создадим схему для демонстрации работы с цифровыми выходами Arduino UNO, управляя миганием шести светодиодов.

### Необходимые компоненты

- Arduino UNO
- 6 зелёных светодиодов
- 6 резисторов на 220 Ом
- Провода для соединения компонентов

### Инструкция по сборке схемы

1. Вставьте резисторы на 220 Ом в макетную плату.
2. Подключите аноды (длинные ножки) светодиодов к свободным концам резисторов.
3. Подключите катоды (короткие ножки) светодиодов к общему заземляющему (GND) выводу на Arduino UNO.
4. Подключите другие концы резисторов к цифровым выводам D1, D2, D3, D4, D5 и D6 на Arduino UNO.

### Схема подключения

### Код программы

```cpp
// Управляемые контакты на Arduino
int Led1 = 1;
int Led2 = 2;
int Led3 = 3;
int Led4 = 4;
int Led5 = 5;
int Led6 = 6;

void setup() {
    for (int i = 1; i <= 6; i++) {  // Пины 1–6 как выходы
        pinMode(i, OUTPUT);
    }
}

void loop() {
    for (int j = 1; j <= 6; j++) {
        digitalWrite(j, HIGH);  // Включаем светодиоды по очереди
        delay(200);
    }
    for (int j = 6; j >= 1; j--) {
        digitalWrite(j, LOW);   // Выключаем в обратном порядке
        delay(200);
    }
}
```

### Принцип работы схемы

Схема управляет миганием шести светодиодов с помощью цифровых выходов Arduino UNO. Выходы переключают светодиоды между включённым и выключенным состояниями, создавая эффект последовательного мигания.

- **Инициализация.** В `setup()` пины D1–D6 настраиваются как выходы в цикле `for`.
- **Управление.** В `loop()` светодиоды последовательно включаются (HIGH) и выключаются (LOW) в обратном порядке.
- **Задержка.** `delay(200)` — 200 мс между переключениями для плавного эффекта.
- **Роль резисторов.** Резисторы на 220 Ом ограничивают ток через светодиоды.

Схема демонстрирует управление несколькими выходами и использование циклов в программе.

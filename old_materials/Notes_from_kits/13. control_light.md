## Индикатор уровня освещённости

Создадим схему, позволяющую демонстрировать работу с аналоговыми и цифровыми выходами Arduino UNO для индикации уровня освещённости с помощью светодиодов.

### Необходимые компоненты

- Arduino UNO
- Фоторезистор (LDR)
- 8 светодиодов (красные)
- 9 резисторов на 10 кОм
- Провода для соединения компонентов

### Инструкция по сборке схемы

1. Подключите фоторезистор к аналоговому входу A0 на Arduino UNO (один конец фоторезистора к 5 V, другой — к резистору 10 кОм, второй вывод резистора к GND, образуя делитель напряжения).
2. Подключите аноды светодиодов к цифровым выводам D3–D10 на Arduino UNO через резисторы на 10 кОм.
3. Подключите катоды всех светодиодов к GND на Arduino UNO.

### Схема подключения

### Код программы

```cpp
const int leds[] = {3, 4, 5, 6, 7, 8, 9, 10};  // пины светодиодов
const int LIGHT = A0;       // фоторезистор на A0
const int MIN_LIGHT = 200;  // нижний порог освещённости
const int MAX_LIGHT = 900;  // верхний порог освещённости
int val = 0;

void setup() {
    for (int i = 0; i < 8; i++)
        pinMode(leds[i], OUTPUT);
}

void loop() {
    val = analogRead(LIGHT);                           // считываем фоторезистор
    val = map(val, MIN_LIGHT, MAX_LIGHT, 8, 0);       // преобразуем в число светодиодов (8–0)
    val = constrain(val, 0, 8);                        // ограничиваем диапазон
    for (int i = 1; i < 9; i++) {
        if (i >= val)
            digitalWrite(leds[i - 1], HIGH);           // зажечь
        else
            digitalWrite(leds[i - 1], LOW);            // потушить
    }
    delay(1000);
}
```

### Принцип работы схемы

Схема использует фоторезистор для измерения освещённости. Фоторезистор вместе с резистором 10 кОм образует делитель напряжения; напряжение с середины делителя подаётся на A0. При высокой освещённости сопротивление LDR падает, напряжение на A0 растёт; при низкой — наоборот.

Функция `map(val, MIN_LIGHT, MAX_LIGHT, 8, 0)` преобразует значение с A0 (200–900) в число светодиодов (8–0): при ярком свете — больше светодиодов, при слабом — меньше. `constrain()` ограничивает значение диапазоном 0–8. В цикле зажигаются светодиоды с номерами от 1 до val, остальные гаснут. Резисторы 10 кОм ограничивают ток через светодиоды.

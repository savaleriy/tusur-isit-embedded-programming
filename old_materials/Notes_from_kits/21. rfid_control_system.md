## Система контроля доступа на базе RFID

Создадим схему, объединяющую RFID-RC522 и реле: при поднесении разрешённой карты реле включается на 2 секунды (можно использовать для управления замком или другим устройством).

### Необходимые компоненты

- Arduino UNO
- Модуль RFID-RC522
- Одноканальное реле 5 V (10 A)
- Провода для соединения

### Инструкция по сборке схемы

**RFID-RC522:** 3.3 V → 3.3 V, GND → GND, RST → D7, MISO → D12, MOSI → D11, SCK → D13, SDA → D10.

**Реле:** сигнальный вход (S/SIG/IN) → D6, питание (VCC/5V) → 5 V, земля (GND) → GND.

_Важно: маркировка выводов реле различается у разных производителей (S, IN, SIG для сигнала; VCC, 5V для питания). Сверяйтесь с документацией вашего модуля перед подключением._

### Код программы

```cpp
#include <SPI.h>
#include <MFRC522.h>

#define RELAY_PIN 6
#define RELAY_ON 0
#define RELAY_OFF 1
#define RST_PIN 7
#define SS_PIN 10

MFRC522 mfrc522(SS_PIN, RST_PIN);

byte authorizedUIDs[][4] = {
    {0x12, 0x34, 0x56, 0x78},
    {0xAB, 0xCD, 0xEF, 0x12},
    {0x98, 0x76, 0x54, 0x32}
};
int numAuthorizedCards = 3;

void setup() {
    Serial.begin(9600);
    SPI.begin();
    mfrc522.PCD_Init();
    pinMode(RELAY_PIN, OUTPUT);
    digitalWrite(RELAY_PIN, RELAY_OFF);
    Serial.println("Система контроля доступа готова");
}

void loop() {
    if (mfrc522.PICC_IsNewCardPresent() && mfrc522.PICC_ReadCardSerial()) {
        Serial.print("UID: ");
        for (byte i = 0; i < mfrc522.uid.size; i++) {
            Serial.print(mfrc522.uid.uidByte[i] < 0x10 ? " 0" : " ");
            Serial.print(mfrc522.uid.uidByte[i], HEX);
        }
        Serial.println();

        if (compare_uid(mfrc522.uid.uidByte, mfrc522.uid.size)) {
            Serial.println("Доступ разрешён!");
            digitalWrite(RELAY_PIN, RELAY_ON);
            delay(2000);
            digitalWrite(RELAY_PIN, RELAY_OFF);
        } else {
            Serial.println("Доступ запрещён!");
        }
        mfrc522.PICC_HaltA();
    }
    delay(100);
}

boolean compare_uid(byte *buffer, byte bufferSize) {
    for (int i = 0; i < numAuthorizedCards; i++) {
        if (bufferSize != 4) continue;
        bool match = true;
        for (byte j = 0; j < 4; j++) {
            if (buffer[j] != authorizedUIDs[i][j]) { match = false; break; }
        }
        if (match) return true;
    }
    return false;
}
```

### Принцип работы схемы

В массиве `authorizedUIDs` хранятся UID разрешённых карт (замените на реальные, считанные программой из урока «Считыватель RFID-карт»). При поднесении карты её UID сравнивается со списком; при совпадении реле включается на 2 секунды. Реле может быть активным по HIGH или по LOW — константы `RELAY_ON` и `RELAY_OFF` задают нужную логику. `PICC_HaltA()` завершает сеанс чтения карты.

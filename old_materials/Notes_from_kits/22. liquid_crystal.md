## Индикатор на ЖК-дисплее

Создадим схему для отображения текста на ЖК-дисплее 16×2 с помощью Arduino UNO.

### Необходимые компоненты

- Arduino UNO
- ЖК-дисплей 16×2 (символов)
- Потенциометр (для контрастности)
- Резистор 220 Ом (для подсветки)
- Провода для соединения

### Инструкция по сборке схемы

1. Подключите выводы VSS, K (катод подсветки) и R/W к GND на Arduino UNO.
2. Подключите вывод VDD к 5 V на Arduino UNO.
3. Подключите вывод VO к среднему выводу потенциометра (крайние выводы потенциометра — к 5 V и GND).
4. Подключите RS → D9, E → D8, DB4 → D7, DB5 → D6, DB6 → D5, DB7 → D4.
5. Подключите вывод A (анод подсветки) к 5 V через резистор 220 Ом.

### Схема подключения

![Схема подключения ЖК-дисплея 16×2 к Arduino (4-битный режим)](https://chip-edu.ru/lesson-content/arduino/21/png/display.png)

### Код программы

```cpp
#include <LiquidCrystal.h>

LiquidCrystal lcd(9, 8, 7, 6, 5, 4);  // RS, E, DB4, DB5, DB6, DB7

void setup() {
    lcd.begin(16, 2);
    lcd.setCursor((16 - 5) / 2, 0);
    lcd.print("Hello");
    lcd.setCursor((16 - 8) / 2, 1);
    lcd.print("Arduino!");
}

void loop() {
}
```

### Принцип работы схемы

Библиотека LiquidCrystal управляет дисплеем в 4-битном режиме (используются только DB4–DB7). `lcd.begin(16, 2)` задаёт размер 16 столбцов и 2 строки. `setCursor(col, row)` устанавливает позицию курсора; `print()` выводит текст. Потенциометр на VO регулирует контрастность; резистор 220 Ом ограничивает ток подсветки. В данном примере текст выводится один раз в `setup()` и остаётся на экране.

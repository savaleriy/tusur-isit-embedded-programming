## Диммируемый светодиод

Создадим схему для демонстрации работы с аналоговыми выходами Arduino UNO, позволяющую управлять яркостью светодиода путём его плавного включения и выключения (диммирования).

### Необходимые компоненты

- Arduino UNO
- Жёлтый светодиод
- Резистор на 220 Ом
- Провода для соединения компонентов

### Инструкция по сборке схемы

1. Вставьте резистор на 220 Ом в макетную плату.
2. Подключите анод (длинная ножка) светодиода к свободному концу резистора.
3. Подключите катод (короткая ножка) светодиода к одному из заземляющих (GND) выводов на Arduino UNO.
4. Подключите другой конец резистора к цифровому выводу D9 на Arduino UNO, который поддерживает ШИМ.

### Схема подключения

![Схема подключения диммируемого светодиода к Arduino (пин D9)](https://chip-edu.ru/lesson-content/arduino/3/png/dimmable_led.png)

### Код программы

```cpp
int led = 9;           // вывод светодиода 9
int brightness = 0;    // переменная яркости
int fadeAmount = 5;    // шаг изменения яркости за цикл

void setup() {
    pinMode(led, OUTPUT);  // вывод 9 как выход
}

void loop() {
    analogWrite(led, brightness);

    brightness = brightness + fadeAmount;

    if (brightness <= 0 || brightness >= 255) {
        fadeAmount = -fadeAmount;  // меняем направление
    }

    delay(30);  // задержка для плавного эффекта
}
```

### Принцип работы схемы

Схема использует ШИМ (широтно-импульсную модуляцию) микроконтроллера Arduino UNO для плавного изменения яркости светодиода. ШИМ позволяет менять среднее напряжение на светодиоде, переключая вывод между высоким и низким уровнем с разной скважностью.

- **Инициализация.** В `setup()` вывод D9 настраивается как выход с поддержкой ШИМ.
- **Диммирование.** В `loop()` функция `analogWrite()` задаёт яркость значением от 0 до 255; яркость плавно увеличивается и уменьшается за счёт `fadeAmount`.
- **Задержка.** `delay(30)` создаёт видимый плавный переход.
- **Роль резистора.** Резистор на 220 Ом ограничивает ток через светодиод.

Таким образом, схема демонстрирует использование ШИМ для диммирования светодиода и работу с аналоговыми выходами Arduino.

### Примечание

`digitalWrite()` и `analogWrite()` — функции Arduino для управления выводами, но они работают по-разному:

#### digitalWrite()

- **Назначение:** устанавливает цифровой (двоичный) сигнал на вывод.
- **Значения:** HIGH (5 В) или LOW (0 В).
- **Пины:** любой цифровой пин.
- **Как работает:** полностью включает или выключает питание на пине.

Пример: включение/выключение светодиода, реле.

```cpp
digitalWrite(13, HIGH);  // Подать 5 В на пин 13
digitalWrite(13, LOW);   // Подать 0 В на пин 13
```

#### analogWrite()

- **Назначение:** генерирует ШИМ (PWM) для имитации аналогового напряжения.
- **Значения:** от 0 до 255 (8 бит) — скважность ШИМ.
- **Пины:** только пины с ШИМ (~) на плате (на Arduino Uno: 3, 5, 6, 9, 10, 11).
- **Как работает:** быстро переключает пин с переменной скважностью, создавая среднее напряжение от 0 до 5 В.

Пример: плавная яркость светодиода, скорость двигателя.

```plaintext
analogWrite(9, 0);    // 0% — среднее 0 В
analogWrite(9, 127);  // ~50% — среднее ~2,5 В
analogWrite(9, 255);  // 100% — среднее 5 В
```

|Параметр|digitalWrite|analogWrite|
|---|---|---|
|Тип сигнала|Цифровой (0 или 1)|ШИМ (имитация аналогового)|
|Диапазон|2 состояния|256 градаций (0–255)|
|Напряжение|0 В или 5 В|Среднее от 0 до 5 В|
|Пины|Все цифровые|Только с ШИМ|
|Частота ШИМ|—|Обычно 490 Гц или 980 Гц|

**Важно!** `analogWrite()` не даёт истинное аналоговое напряжение — для этого нужен ЦАП (DAC), как на Arduino Due. На пинах без ШИМ `analogWrite()` работать не будет. Для получения постоянного напряжения из ШИМ часто используют RC-фильтр.

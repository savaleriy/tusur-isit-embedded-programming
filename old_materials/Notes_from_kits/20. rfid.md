## Считыватель RFID-карт

Создадим схему для демонстрации работы с RFID-технологией, используя модуль RFID-RC522 и Arduino UNO для считывания идентификаторов RFID-карт и меток.

### Необходимые компоненты

- Arduino UNO
- Модуль RFID-RC522
- Провода для соединения компонентов

### Инструкция по сборке схемы

1. Подключите 3.3 V модуля к 3.3 V на Arduino UNO.
2. Подключите GND модуля к GND на Arduino UNO.
3. Подключите RST модуля к цифровому выводу D7.
4. Подключите MISO модуля к D12, MOSI — к D11, SCK — к D13.
5. Подключите SDA модуля к цифровому выводу D10.

### Код программы

```cpp
#include <SPI.h>
#include <MFRC522.h>

#define RST_PIN 7
#define SS_PIN 10

MFRC522 mfrc522(SS_PIN, RST_PIN);

void setup() {
    Serial.begin(9600);
    SPI.begin();
    mfrc522.PCD_Init();
}

void loop() {
    if (!mfrc522.PICC_IsNewCardPresent())
        return;
    if (!mfrc522.PICC_ReadCardSerial())
        return;

    Serial.print(F("Card UID:"));
    for (byte i = 0; i < mfrc522.uid.size; i++) {
        Serial.print(mfrc522.uid.uidByte[i] < 0x10 ? " 0" : " ");
        Serial.print(mfrc522.uid.uidByte[i], HEX);
    }
    Serial.println();

    Serial.print(F("PICC type: "));
    Serial.println(mfrc522.PICC_GetTypeName(mfrc522.PICC_GetType(mfrc522.uid.sak)));

    delay(2000);
}
```

### Принцип работы схемы

Модуль RC522 связывается с Arduino по SPI: SDA (SS) — D10, SCK — D13, MOSI — D11, MISO — D12, RST — D7. Питание — 3.3 V.

Библиотека MFRC522 инициализирует модуль в `setup()`. В `loop()` проверяется появление карты (`PICC_IsNewCardPresent`) и чтение её серийного номера (`PICC_ReadCardSerial`). UID выводится в шестнадцатеричном виде, затем тип карты. Пауза 2 секунды ограничивает частоту опроса.

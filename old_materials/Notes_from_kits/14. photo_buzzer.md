## Фотосенсорный зуммер

Создадим схему, которая использует фотосенсор (LDR) для управления частотой звука пьезоизлучателя, подключённого к Arduino UNO.

### Необходимые компоненты

- Arduino UNO
- Фотосенсор (LDR)
- Резистор на 10 кОм
- Пьезоизлучатель (зуммер)
- Провода для соединения компонентов

### Инструкция по сборке схемы

1. Подключите один вывод фотосенсора к 5 V на Arduino UNO.
2. Подключите другой вывод фотосенсора к аналоговому входу A3 на Arduino UNO.
3. Подключите один вывод резистора на 10 кОм к аналоговому входу A3 (к точке соединения с фотосенсором).
4. Подключите другой вывод резистора к GND на Arduino UNO.
5. Подключите один вывод пьезоизлучателя к цифровому выводу D5 на Arduino UNO.
6. Подключите другой вывод пьезоизлучателя к GND на Arduino UNO.

### Схема подключения

### Код программы

```cpp
#define buzzerPin 5   // зуммер на D5
#define photoPin A3   // фоторезистор на A3

int aVal;
int sMax = 1023;      // макс. значение АЦП (10 бит)
long buzzerFreq;
const long BUZZ_FREQ_MAX = 2500;

void setup() {
    pinMode(buzzerPin, OUTPUT);
    Serial.begin(9600);
}

void loop() {
    aVal = analogRead(photoPin);
    Serial.print("aVal: ");
    Serial.println(aVal);
    buzzerFreq = (aVal * BUZZ_FREQ_MAX) / sMax;  // частота пропорциональна освещённости
    buzz(buzzerPin, buzzerFreq, 10);
}

void buzz(int targetPin, long frequency, long length) {
    long delayValue = 1000000 / frequency / 2;   // полуволна в микросекундах
    long numCycles = frequency * length / 1000;
    for (long i = 0; i < numCycles; i++) {
        digitalWrite(targetPin, HIGH);
        delayMicroseconds(delayValue);
        digitalWrite(targetPin, LOW);
        delayMicroseconds(delayValue);
    }
}
```

### Принцип работы схемы

Фотосенсор с резистором 10 кОм образует делитель напряжения; напряжение с A3 зависит от освещённости. Чем выше освещённость, тем ниже сопротивление LDR, тем выше напряжение и значение `aVal` (0–1023).

Частота звука вычисляется как `buzzerFreq = (aVal * BUZZ_FREQ_MAX) / sMax` — от 0 до 2500 Гц. Функция `buzz()` генерирует меандр заданной частоты: переключает пин HIGH/LOW с паузой `delayValue` (полупериод), повторяя циклы в течение `length` миллисекунд. В итоге чем ярче свет, тем выше тон зуммера.

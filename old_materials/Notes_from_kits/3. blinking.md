## Мигающий светодиод

Создадим простую схему для демонстрации работы с цифровыми выходами Arduino UNO путём управления миганием светодиода.

### Необходимые компоненты

- Arduino UNO
- Красный светодиод
- Резистор на 220 Ом
- Провода для соединения компонентов

### Инструкция по сборке схемы

1. Вставьте резистор на 220 Ом в макетную плату.
2. Подключите анод (длинная ножка) светодиода к свободному концу резистора.
3. Подключите катод (короткая ножка) светодиода к одному из заземляющих (GND) выводов на Arduino UNO.
4. Подключите другой конец резистора к цифровому выводу D12 на Arduino.

### Схема подключения

![Схема подключения мигающего светодиода к Arduino](https://chip-edu.ru/lesson-content/arduino/2/png/flashing_led.png)

### Код программы

```cpp
int led = 12;  // Контакт 12 подключен к светодиоду через резистор

void setup() {
    pinMode(led, OUTPUT);  // Инициализация цифрового вывода как выход
}

void loop() {
    digitalWrite(led, HIGH);  // Включить светодиод
    delay(1000);
    digitalWrite(led, LOW);   // Выключить светодиод
    delay(1000);
}
```

### Принцип работы схемы

Схема использует цифровой выход микроконтроллера для переключения светодиода между включённым и выключенным состояниями, создавая эффект мигания.

- **Инициализация.** В функции `setup()` вывод D12 настраивается как выход командой `pinMode(led, OUTPUT)` — микроконтроллер может устанавливать на нём уровень HIGH или LOW.
- **Включение.** В `loop()` команда `digitalWrite(led, HIGH)` устанавливает D12 в HIGH — через светодиод протекает ток (анод через резистор к D12, катод к GND), светодиод светится.
- **Задержка.** `delay(1000)` — пауза 1 секунда, светодиод остаётся включённым.
- **Выключение.** `digitalWrite(led, LOW)` — ток через светодиод не идёт, он гаснет.
- **Повтор.** Снова `delay(1000)`, затем цикл повторяется.

**Роль резистора:** резистор на 220 Ом ограничивает ток через светодиод, создаёт падение напряжения и защищает светодиод от повреждения.

# Задачи

## 1. Светофор с кнопками
Необходимо реализовать светофор с управлением по нажатию кнопки.
## 2. Дистанция до Цели.
Необходимо реализовать систему, используя **HC-SR04** ультразвуковой датчик расстояния (интерфейс: **цифровые пины** для Trig и Echo) и **RGB-светодиод** (интерфейс: **3 ШИМ-выхода** для красного, зеленого и синего каналов). Система вычисляет расстояние до цели и сигнализирует результат: зеленый — безопасная дистанция, желтый — средняя, красный — критическая.

## 3. Сигнализация
Реализуйте систему сигнализации с двумя **HC-SR04** датчиками (интерфейс каждого: **цифровые пины** — Trig1/Echo1, Trig2/Echo2). Добавьте два отдельных светодиода (интерфейс: **цифровые выходы**) для индикации срабатывания каждого датчика. Зоны сканирования должны пересекаться. Когда объект находится в зоне одного датчика — мигает соответствующий светодиод, в зоне пересечения — горят оба светодиода постоянно. В дежурном режиме мигает встроенный светодиод на плате (пин 13).

## 4. Система проверки температуры
Пользователь нажимает кнопку (интерфейс: **цифровой вход** с подтяжкой) для начала измерения. Система измеряет расстояние до пользователя с помощью **HC-SR04** (интерфейс: **цифровые пины**). При достижении расстояния 10-30 см измеряется температура с помощью **DHT22** (интерфейс: **1-Wire** на цифровом пине). Результат выводится в **Serial Monitor** (интерфейс: **UART** через USB). Визуальная индикация: зеленый светодиод (цифровой выход) — норма, красный светодиод (цифровой выход) — отклонение.

## 5. Крутое Пике Бройлера 747
Разработайте систему мониторинга полета, используя **MPU6050** (акселерометр и гироскоп, интерфейс: **I2C**), а также датчик температуры **DS18B20** (интерфейс: **1-Wire**). Данные с датчиков выводятся на **OLED-дисплей 0.96"** (интерфейс: **I2C**). При превышении угла крена, ускорения или температуры система подает звуковой сигнал через пьезодинамик (интерфейс: **ШИМ-выход**) и включает красный светодиод (цифровой выход).

## 6. Термостат с памятью настроек

Разработайте систему термостата с датчиком **DHT22** (интерфейс: 1-Wire) и потенциометром для задания пороговой температуры. Измеренная и пороговая температуры выводятся на **LCD 1602** (I2C). При превышении порога включается реле (управление через транзистор). Значение порога должно сохраняться в **EEPROM** при долгом нажатии кнопки и восстанавливаться при включении.

## 7. Простой вольтметр с пороговой сигнализацией
Создайте вольтметр, измеряющий напряжение (0-5В) с помощью **встроенного АЦП** через делитель напряжения. Результат в вольтах выводится в **Serial Monitor** (UART). Добавьте два светодиода (зеленый/красный), которые зажигаются при нахождении напряжения в допустимом диапазоне или выходе за его пределы. Диапазон задается двумя потенциометрами, подключенными к другим входам АЦП.

## 8. Генератор тонального сигнала с ШИМ
Реализуйте генератор звукового сигнала с помощью **ШИМ** и пьезодинамика. Частота генерируемого тона задается потенциометром через АЦП. Используйте таймер для точной установки частоты ШИМ. Добавьте кнопку для включения/выключения звука и светодиод-индикатор работы.

## 9. Система учета нажатий с энергонезависимой памятью
Создайте счетчик нажатий кнопки. Каждое нажатие увеличивает счетчик, значение которого отображается на **семисегментном индикаторе** (подключение через сдвиговый регистр 74HC595, интерфейс SPI). Текущее значение счетчика должно сохраняться в **EEPROM** каждые 10 нажатий и при отключении питания восстанавливаться.

## 10. Калибровка датчика освещенности
Настройте систему с фоторезистором (подключен к **АЦП**) и двумя кнопками. При нажатии первой кнопки система записывает текущее значение освещенности как "мин." в **EEPROM**, при нажатии второй — как "макс.". В рабочем режиме система мапит текущие показания на диапазон 0-100% и выводит процент на **Serial Plotter** (UART).

## 11. Таймер обратного отсчета с сигнализацией
Реализуйте таймер обратного отсчета. Время (от 1 до 99 секунд) задается с помощью энкодера и отображается на **семисегментном индикаторе** (SPI через сдвиговый регистр). Запуск по кнопке. По истечении времени включается звуковая сигнализация (ШИМ на пьезодинамик) и мигает светодиод. Используйте прерывания таймера для точного отсчета.

## 12. Управление сервоприводом по аналоговому сигналу
Создайте систему управления сервоприводом (интерфейс: ШИМ) с помощью потенциометра. Угол поворота сервопривода должен соответствовать положению ручки потенциометра (значение с **АЦП**). Добавьте кнопку-фиксатор: при нажатии текущее положение записывается в **EEPROM**, а при включении система автоматически устанавливает серву в запомненное положение.

## 13. Мониторинг температуры с графиком
Реализуйте систему мониторинга температуры с датчиком **DS18B20** (1-Wire). Температура измеряется каждые 2 секунды (использование таймера) и выводится в **Serial Plotter** (UART) для построения графика. При превышении порога (задается потенциометром через АЦП) зажигается красный светодиод.

## 15. Цифровая шкала уровня сигнала
Создайте шкалу из 8 светодиодов, отображающую уровень аналогового сигнала с микрофонного модуля (подключен к **АЦП**). Чем громче звук, тем больше светодиодов зажигается. Используйте сдвиговый регистр **74HC595** (SPI) для управления светодиодами. Добавьте потенциометр для регулировки чувствительности.

## 16. Часы с будильником на RTC

Время срабатывания будильника хранится в **EEPROM**. При срабатывании включается звуковой сигнал (ШИМ) и мигает светодиод.

## 17. Система пароля на основе последовательности
Реализуйте систему доступа с паролем из 4-х цифр. Цифры вводятся с помощью энкодера (поворот - выбор цифры 0-9, нажатие - подтверждение). Введенная последовательность отображается на **семисегментном индикаторе** (SPI). Правильный пароль хранится в **EEPROM**. При верном вводе зажигается зеленый светодиод и включается реле на 5 секунд, при неверном - красный.

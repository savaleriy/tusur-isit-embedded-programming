# Занятие 18. Задачи

**Оборудование:** Arduino UNO, светодиоды, кнопки, потенциометр, резисторы. Сборка - в PlatformIO без фреймворка Arduino (`framework` не указан).

---

## 18.1. Мигание без Arduino

**Описание.** Напишите первую программу на чистом C.

**Требования.**

1. Проект PlatformIO без строки `framework`, файл `src/main.c` с функцией `main()`.
2. Светодиод на выводе D13 мигает с периодом 1 секунда, использованы только `avr/io.h` и `util/delay.h`.
3. Реализованы **три** варианта переключения вывода: через `PORTB |= / &= ~`, через `PORTB ^=` и через запись в `PINB`.
4. Для каждого варианта приведите объём Flash и SRAM.
5. Сравните с эквивалентным скетчем Arduino: приведите обе цифры и разницу в процентах и в байтах.

**Вопрос.** Из чего складываются те 900 байт, которые занимает пустой скетч Arduino? Что делает функция `init()` из ядра?

## 18.2. Битовые операции

**Описание.** Отработайте работу с отдельными битами.

**Требования.**

1. Восемь светодиодов подключены к одному порту целиком (например, PORTD - выводы D0-D7; на время задания отключите Serial).
2. Реализуйте функции: установить бит, сбросить бит, инвертировать бит, прочитать бит - через макросы.
3. Реализуйте "бегущий огонь" **одной операцией сдвига** переменной, без цикла по выводам.
4. Реализуйте эффект "заполнение": светодиоды загораются по одному, оставаясь включёнными.
5. Кнопка на другом порту переключает эффекты.

**Вопрос.** Дано `x = 0b01101101` и `y = 0b11101110`. Вычислите вручную и проверьте программой: `x & y`, `x | y`, `x ^ y`, `~x`, `x << 2`, `x >> 3`.

## 18.3. АЦП на регистрах

**Описание.** Настройте аналого-цифровой преобразователь без `analogRead()`.

**Требования.**

1. Реализуйте функции `adc_init()` и `adc_read(channel)` по образцу из конспекта.
2. Значение потенциометра отображается шкалой из светодиодов.
3. Реализуйте **свой** `uart_init()` и `uart_print()` и выводите значение в монитор порта.
4. Сравните время выполнения вашего `adc_read()` и `analogRead()` из Arduino - приведите обе цифры в микросекундах.
5. Поэкспериментируйте с предделителем АЦП: измерьте время преобразования и разброс показаний при делителях 128, 64, 16. Сведите в таблицу.

**Вопрос.** Почему документация рекомендует держать частоту АЦП в диапазоне 50-200 кГц? Что вы наблюдали при выходе за этот диапазон?

## 18.4. Прерывания и таймер на регистрах

**Описание.** Настройте внешнее прерывание и таймер без функций Arduino.

**Требования.**

1. Внешнее прерывание `INT0` на выводе D2 настроено через регистры `EICRA` и `EIMSK`, обработчик написан через макрос `ISR()`.
2. Timer1 в режиме CTC вызывает прерывание ровно раз в секунду; расчёт регистров приведите в отчёте.
3. В обработчике таймера переключается светодиод записью в `PINB`.
4. Обработчик кнопки увеличивает счётчик нажатий; значение раз в секунду выводится вашей функцией UART.
5. Переменные, общие с обработчиками, объявлены `volatile`; многобайтные читаются в критической секции.

**Вопрос.** Опишите, что делает каждый бит, который вы записали в регистры `EICRA`, `EIMSK`, `TCCR1B` и `TIMSK1`. Ссылайтесь на разделы документации.

## 18.5. Ассемблерные вставки

**Описание.** Примените ассемблер там, где он оправдан.

**Требования.**

1. Реализуйте функцию точной задержки на заданное количество тактов через `nop`.
2. Реализуйте атомарное чтение 16-битной переменной через сохранение и восстановление `SREG` ассемблерной вставкой.
3. Сформируйте на выводе прямоугольный сигнал максимально возможной частоты и измерьте её.
4. Сравните три способа получения максимальной частоты: `digitalWrite()`, запись в `PORTB`, ассемблерная вставка `sbi`/`cbi`. Приведите три цифры.

**Вопро.** Какова теоретически максимальная частота переключения вывода на 16 МГц и почему на практике она получается ниже?

## 18.6. Сравнение уровней абстракции

**Описание.** Реализуйте одну задачу тремя способами.

**Задача:** кнопка на выводе D2 переключает светодиод на D13, дребезг подавлен, программа не блокирует выполнение.

**Требования.**

1. **Вариант A:** фреймворк Arduino, классы с [занятия 11](../11-cpp-oop/note.md).
2. **Вариант B:** чистый C, прямая работа с регистрами, время по Timer1.
3. **Вариант C:** чистый C с прерываниями - кнопка на `INT0`, время по прерыванию таймера.
4. Для каждого варианта приведите: объём Flash, объём SRAM, количество строк кода, субъективную оценку читаемости и времени разработки.
5. Сведите всё в таблицу и сформулируйте, в каких условиях вы бы выбрали каждый вариант.

**Вопрос.** Сформулируйте собственное правило: когда стоит спускаться на уровень регистров, а когда это преждевременная оптимизация?

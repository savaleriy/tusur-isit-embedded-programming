# Занятие 11. Задачи

**Оборудование:** Arduino UNO, PlatformIO, кнопки, светодиоды, джойстик KY-023, светодиодная матрица 8x8, сдвиговый регистр 74HC595, семисегментный индикатор.

> Все задачи выполняются в PlatformIO. Классы размещаются в `lib/`, программа - в `src/main.cpp`.

---

## 11.1. От модуля к классу

**Описание.** Перепишите модуль из задачи 6.6 в виде класса.

**Требования.**

1. Класс `Filter` с настраиваемым коэффициентом сглаживания, реализующий бегущее среднее.
2. Поля закрыты, интерфейс состоит из конструктора и методов `reset()`, `add(value)`, `value()`.
3. Метод получения значения помечен `const`.
4. Программа создаёт **два независимых** объекта фильтра для двух разных датчиков и выводит в Serial Plotter четыре кривые: два сырых сигнала и два отфильтрованных.

## 11.2. Класс кнопки

**Описание.** Реализуйте класс `Button` по образцу из конспекта и примените его.

**Требования.**

1. Класс поддерживает: подавление дребезга, определение фронта нажатия и отпускания, длинное нажатие, измерение длительности нажатия.
2. Полярность (`activeLow`) и время подавления дребезга задаются в конструкторе со значениями по умолчанию.
3. Программа использует **массив из трёх кнопок**, обрабатываемый циклом по диапазону.
4. Каждая кнопка управляет своим светодиодом: короткое нажатие переключает, длинное - включает режим мигания.
5. `delay()` в программе не используется.

**Эксперимент.** Замените в цикле `for (auto &b : buttons)` на `for (auto b : buttons)` и опишите, что произойдёт с работой кнопок и почему.

## 11.3. Собственная библиотека

**Описание.** Разработайте, оформите и задокументируйте полноценную библиотеку для одного из устройств набора.

**Выберите один вариант:**

### Вариант А. Джойстик KY-023.

Класс `Joystick`:

- автоматическая калибровка центра при `begin()`;
- настраиваемая мёртвая зона;
- методы `x()` и `y()`, возвращающие нормализованное значение -100...+100;
- метод `direction()`, возвращающий одно из значений `enum class Direction { None, Up, Down, Left, Right, UpLeft, ... }`;
- встроенная кнопка обрабатывается с подавлением дребезга, есть `wasPressed()`;
- метод `update()` для неблокирующей работы.

### Вариант Б. Светодиодная матрица 8x8.

Класс `LedMatrix`:

- работа через сдвиговый регистр (столбцы) и выводы Arduino (строки);
- буфер кадра 8 байт в оперативной памяти;
- методы `setPixel(x, y, on)`, `clear()`, `fill()`, `drawImage(const uint8_t *image)`;
- метод `refresh()` для построчной развёртки, пригодный для вызова из прерывания таймера;
- изображения могут храниться во Flash (`PROGMEM`);
- методы сдвига картинки `shiftLeft()`, `shiftRight()` для бегущей строки.

**Требования к любому варианту.**

1. Библиотека лежит в `lib/<Имя>/src/` и подключается как `#include <Имя.h>`.
2. Заголовочный файл содержит комментарий с описанием, схемой подключения и примером использования.
3. Все поля - `private`, наружу выведен только осмысленный интерфейс.
4. Номера выводов задаются **в конструкторе**, а не жёстко внутри библиотеки.
5. Внутри библиотеки **нет** `delay()`, `Serial.print()`, `String` и динамического выделения памяти.
6. Есть файл `library.json` с метаданными.
7. Есть `README.md`: назначение, схема подключения, таблица методов, пример.
8. В папке `examples/` лежит рабочий пример.
9. Программа в `src/main.cpp` демонстрирует все возможности библиотеки.
10. Проект собирается с флагами `-Wall -Wextra` без предупреждений.

Мочь ответить на вопросы:

- обоснование выбора публичного интерфейса: почему именно эти методы;
- перечень того, что вы сознательно оставили `private`, и почему;
- описание одного проектного решения, которое вы поменяли в процессе работы, и причину.

## 11.6. Ревизия кода на C++

**Описание.** Найдите и исправьте типичные ошибки применения C++ на AVR.

**Требования.** Дан фрагмент (перепишите его в свой проект и исправьте):

```cpp
class Logger {
public:
    String buffer;

    void add(String message) {
        buffer = buffer + message + "\n";
    }

    void flush() {
        Serial.print(buffer);
        buffer = "";
    }
};

Logger logger;

void loop() {
    logger.add("T=" + String(analogRead(A0)));
    delay(100);
    if (millis() % 5000 == 0) logger.flush();
}
```

1. Перечислите **все** проблемы этого кода: работа с памятью, интерфейс, логика, стиль.
2. Перепишите класс без `String` и без динамической памяти, с буфером фиксированного размера.
3. Измерьте свободную SRAM в исходной и исправленной версиях после 5 минут работы. Приведите обе цифры.
4. Объясните, почему условие `millis() % 5000 == 0` работает ненадёжно, и исправьте его.
